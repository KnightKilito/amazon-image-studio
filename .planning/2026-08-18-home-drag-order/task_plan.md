# 首页图片拖拽排序偶发失效修复

## Goal

定位首页图片拖拽排序偶发失效的根因，实施稳健修复，并通过自动化测试与本地交互验证。

## Phases

- [completed] 审计首页拖拽排序事件链、状态与现有测试。
- [completed] 实施针对性修复并补充回归测试。
- [completed] 运行测试、构建、页面交互与差异检查。

## Decisions

- 保留并绕开用户已有改动，只修改拖拽排序相关文件。
- 使用内部专用 MIME 区分缩略图排序与外部图片上传。
- 由缩略图网格统一计算释放点，桌面端和触屏端共用可覆盖间隙、跨行位置的落点算法。

## Errors Encountered

- 浏览器自动化的原生 CUA 拖拽未能稳定触发 HTML5 drag 事件；通过页面命中检查发现全覆盖编辑按钮未声明 draggable，并据此修复拖拽入口。最终以纯落点算法回归、完整测试、生产构建及页面 DOM/控制台检查共同验证。
