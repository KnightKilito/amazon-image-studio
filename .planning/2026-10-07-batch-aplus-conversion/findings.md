# Findings
- submitTask 已有 explicitInput，但会修改全局参数、pending category 与当前编辑任务，需要增加后台提交选项及可等待句柄。
- API 层已接受 AbortSignal；普通任务执行层与重连链需要接入并加终态检查。
- 现有单张转换直接替换 inputImages；需独立准备状态并在编辑提交入口限定单张源图。
- 本地真实界面验证：默认加载 4 张素材，逐行改描述、片数 3 时尺寸联动到 2928×3600；切换手机联动到 1200×2700，并保留自定义描述；刷新再打开仍保留表格。
- 单张高级/手机弹窗均已通过真实界面检查，高级片数 1–7 尺寸列表与 3 片母图说明正确。
- 回顾重连链发现旧任务刷新恢复会以 running 而非 recoverable 标志启动；终态防护因此同时允许 running/可恢复，禁止已停止状态，避免回归普通 Fal/自定义服务商恢复。
