## 01 开始前的配置

Listing 工作流会使用两类 API 配置。进入右上角 **设置 → API 配置**，分别检查“图片生成”和“AI 策划”：

- AI 策划配置使用可返回文本的 **Responses API** 或 **Chat Completions**。
- 生图配置使用支持图片输出的 **Images API**，或已适配图片输出的服务商。
- 选择的模型具备所选接口权限。自定义直连需自行核对 URL、Key；管理员配置和本站配置不显示连接字段，不需要用户补填。
- 参考图上传数量没有超过管理员设置的统一上限。

> **策划与生图可以使用不同配置**  
> AI 策划按钮使用“策划配置”；右侧提交生图使用当前“生图配置”。切换其中一个不会自动修改另一个。

## 02 准备 Listing 与参考图

1. **选择 Listing 图**：在策划区域顶部切换到 Listing 图，然后选择需要的图片数量和 2K / 4K 档位。
2. **粘贴商品信息**：优先提供完整标题和五点描述。品牌、颜色、材质、目标人群、卖点与包装清单越准确，策划结果越稳定。
3. **上传产品参考图**：建议至少上传清晰的正面、侧面和关键结构图。鞋类可补充鞋底、材质纹理、上脚角度和包装内容。
4. **检查禁止项**：在商品事实里写清不可改变的颜色、结构、配件和文案限制，避免 AI 自行补充不存在的功能。

## 03 选择整套视觉风格

| 模式 | 适合场景 | 使用方式 |
| --- | --- | --- |
| **系统内置** | 需要快速获得稳定、可控的商业视觉。 | 选择预设风格；生成附图时会把对应风格参考图同步到右侧。 |
| **AI 生成** | 希望每个商品拥有更独特的场景、配色与构图语言。 | 先进行 AI 策划，再让 AI 根据商品生成视觉方向和风格参考图。 |

> **MAIN 主图不会套用风格参考图**  
> 亚马逊 MAIN 主图优先保持白底合规和产品真实性。系统会避免把风格参考图自动带入 MAIN 提交；PT 附图才使用整套视觉语言。

## 04 运行 AI 策划

1. **确认 AI 策划配置**：策划按钮旁会显示当前模型和接口。配置不可用时，在设置中选择可用配置；仅自定义直连需要自行填写 Key。管理员配置缺失时请联系管理员。
2. **点击 AI 策划**：AI 会解析商品事实、整理核心卖点，并生成 MAIN + PT01、PT02 等整套方案。
3. **逐张检查策划卡片**：重点检查产品是否准确、每张图的职责是否重复、文字是否适合美国站，以及整套场景是否有变化但仍保持统一。
4. **必要时修改商品信息后重做**：如果产品事实识别错误，优先修正左侧字段或参考图，再重新策划，而不是直接在错误方案上继续生图。

## 05 填入右侧并提交生图

| 按钮 | 提交到右侧的内容 | 建议 |
| --- | --- | --- |
| **带系统提示词** | AI 策划结果 + 产品一致性、Amazon 规则、风格与尺寸约束。 | 默认推荐，适合直接生成正式图片。 |
| **仅策划案** | 只保留当前策划方案和输出要求。 | 适合服务商已有强系统提示词，或你希望自己控制最终 Prompt。 |

填入后请检查右侧四个位置：**提示词、参考图、尺寸、格式与质量**。Listing 和 A+ 工作流默认使用 `PNG` 与 `high`。

> **手动编辑提示词不会被策划案悄悄覆盖**  
> 右侧实际显示的提示词就是提交内容。切换策划卡片或填入方式后，提交前仍可继续手动修改。

## 06 查看结果与继续复用

- 点击历史卡片进入图片详情，可查看参数、参考图、输入内容、分类与创建时间。
- 使用 **编辑输出** 将当前成图作为右侧参考图继续修改。
- 使用 **复用配置** 恢复该任务的提示词、参数与参考图。
- 使用 **转为高级 A+** 或 **转为手机 A+** 重新排版现有图片。
- 点击 **转为手机 A+** 后，需要在弹窗中确认输出由几张手机 A+ 图片合成。普通单图选择 1 张，尺寸为 `1200x900`；3 片连续母图选择 3 张，尺寸为 `1200x2700`。
- 新任务中的母图标记只用于预选张数，历史任务没有标记时默认 1 张，最终始终以用户本次确认的张数为准。
- 策划历史会保存 Listing 输入、参考图、视觉风格与每张策划方案。
- 满意图片可单张下载，也可在历史列表中多选后批量下载。
