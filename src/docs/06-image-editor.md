## 01 进入编辑工作区

在顶部导航点击 **图片编辑**。页面分为三列：

- **素材**：输入图片、风格参考和当前任务输出结果；点击缩略图切换当前查看对象。
- **画布**：预览当前图片，并显示实际像素尺寸。当前输入主图可以直接绘制画布标注。
- **图片编辑**：输入 AI 编辑提示词，或使用局部与本地处理工具。

所有 AI 编辑结果、本地放大结果和切片结果都会写入首页任务历史；结果缩略图可以再次打开编辑工作区。

## 02 上传与选择素材

1. 点击素材栏 **上传**，或把 JPG、PNG、WebP 图片拖到画布区域。
2. 可以一次选择多张图片，数量受管理员设置的参考图上限限制。
3. 点击缩略图在“当前主图”“参考素材”“风格参考”和“结果”之间切换。
4. 只有当前输入主图可以使用遮罩和画布标注。选择其他输入素材时，画布会以预览模式打开。
5. 如需把另一张输入图作为编辑对象，点击画布提示中的 **设为当前主图**。如果当前已有标注，系统会先提示切换主图会清空标注，并清除不匹配的遮罩。

## 03 使用 AI 图片编辑

在右侧输入框写清要修改的内容、保留的内容和构图限制，然后提交编辑任务。建议按“对象 + 动作 + 范围 + 保留约束”描述，例如：

> 只把背景改成浅灰色摄影棚，保持产品外观、角度、颜色、材质和阴影不变，不增加任何文字或道具。

提交前确认当前画布显示的是正确图片。AI 处理中的任务会显示状态，完成或失败后会同步保存到任务历史；失败时先查看错误信息，再调整提示词或参考图。

## 04 局部遮罩编辑

1. 先在素材栏选择输入主图。
2. 点击 **打开遮罩编辑**，在图片上涂抹需要重绘的区域。
3. 只遮罩需要改变的区域，产品主体、品牌标识和不需要变化的结构尽量不要覆盖。
4. 返回图片编辑工作区后，再在输入框中描述局部修改要求并提交。

如果当前选择的是输出结果或风格参考，遮罩按钮会被禁用；请先将输入图设为当前主图。

## 05 预览、下载与继续编辑

右侧工具提供以下操作：

| 操作 | 说明 |
| --- | --- |
| **预览当前图片** | 打开大图预览；如果当前任务有多张输出，可在预览中浏览整组结果。 |
| **下载当前图片** | 下载当前选中的素材或结果，不会修改历史记录。 |
| **将当前结果作为输入继续编辑** | 仅对输出结果启用；会新建一条编辑输入，保留原任务结果。 |
| **设为当前主图** | 将选中的输入素材提升为画布编辑主图，并按提示处理现有标注。 |

## 06 A+ 目标与本地处理

在 **局部与本地处理** 区域先选择目标：

- **Premium A+（桌面）**：每片上传建议 `1464×600`，2K 处理使用 `2928×1200` 的母片尺寸。
- **Mobile A+（手机）**：每片上传建议 `600×450`；2K 处理使用 `1200×900`，4K 处理使用 `2400×1800` 的母片尺寸。

这个目标会影响等比放大和母图切割的校验规格，不会自动改变原图内容。

### 切割 A+ 母图

1. 选择正确的 Premium A+ 或 Mobile A+ 目标，点击 **切割 A+ 母图**。
2. 在弹窗中选择 2-7 张，检查图片真实尺寸和红色虚线分片位置。
3. 系统只按高度等分，不拉伸、不压缩、不静默裁剪；尺寸或比例不符合时不要强行提交。
4. 点击 **切割并保存** 后，原母图保留，切片会作为新的派生任务保存到历史。

### 等比放大图片

- **等比放大图片** 使用浏览器 Canvas 本地处理，不调用 AI、不消耗 Token。
- 系统会根据当前 A+ 目标计算目标尺寸，至少放大 2 倍；低于目标最低上传尺寸时会自动选择更大的倍率。
- 放大结果固定保存为 PNG/high 新任务，原图不会被覆盖，也不会凭空生成新的产品细节。
- 当任务包含多张输出时，工具会提供批量等比放大，所有图片按各自比例处理后保存到同一条新任务。

## 07 准备转为高级 A+ 或手机 A+

图片编辑页底部的 **准备高级 A+** 和 **准备手机 A+** 会把当前图片设置为新的 A+ 编辑输入，并准备对应尺寸/布局提示词。点击后请回到右侧输入框检查提示词、尺寸和参考图，再手动提交；该操作不会直接发起 AI 请求。

如果只是把一张普通结果重新排版为手机 A+，目标选择 Mobile A+；如果是连续母图，请先确认母图片数，再使用切割工具验证每片比例。

## 08 数据与故障排查

- 图片和编辑结果保存在当前浏览器的本地历史中。清空站点数据、使用无痕窗口或更换浏览器可能导致素材无法恢复。
- “打开遮罩编辑”不可用时，检查是否选中了输入主图，而不是结果或风格参考。
- 切片按钮不可用时，确认已选择图片；提交前还需要等待系统读取真实像素尺寸。
- 本地放大失败通常与浏览器无法读取图片、图片数据损坏或存储空间不足有关，可先下载原图后重新上传。
