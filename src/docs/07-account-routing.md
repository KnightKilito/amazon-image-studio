## 01 第一次使用：我需要准备什么

平台模式下，你只需要管理员提供的工作台网址、用户名和初始密码，不需要安装 Docker，也不需要进入 New API 管理端。

当前版本没有自助注册和在线支付。没有账号、忘记密码或需要充值时，请联系管理员。本站账号与你在外部中转站购买服务的账号不是一回事，不能拿中转站的登录密码直接登录本站。

管理员开启过渡期修改密码功能时，可在“设置 → 账户与余额 → 修改登录密码”输入当前密码、新密码及确认密码。修改直接同步本站 New API 账户，成功后使用新密码重新登录；不是修改中转站 Key。入口关闭后请按管理员指引到 New API 处理。忘记当前密码仍需联系管理员重置；已启用额外安全验证的账户需前往 New API 完成验证，不会绕过保护。

如果你使用的是自行部署的纯前端模式，则没有平台登录和本站钱包，需要自己提供 API 连接配置。已有登录会话的用户再次打开平台时，也可能直接进入工作台，不必每次重新输入密码。

登录后，建议按顺序完成：

1. 打开右上角“设置”。
2. 在“API 配置”中确认“图片生成”和“AI 策划”各自选择了什么配置。
3. 确认该配置是否扣本站余额，再开始文案、策划或生图。
4. 重要结果及时下载，定期备份本地历史。

## 02 设置面板怎么找

| 页面 | 普通用户可以做什么 |
| --- | --- |
| 账户与余额 | 查看登录身份、本站钱包、近期本站消费，刷新账单或退出登录 |
| API 配置 | 分别选择生图和策划配置；按权限新建自己的配置，调整模型及高级选项 |
| 习惯配置 | 调整现有工作台操作偏好 |
| 数据管理 | 导入、导出、清理当前浏览器中的个人配置和历史 |

手机端的设置导航在上方，可横向滑动。普通用户没有“管理员设置”，也看不到管理员专用手册，这是权限设计，不是页面缺失。

## 03 三类配置，选择一份就能用

“图片生成”和“AI 策划”各有自己的配置列表。选择配置已经决定了连接与计费方式，不需要再找一个“管理员／自己／代理”的开关。

| 配置 | 如何得到 | 可修改内容 | 消费来源 |
| --- | --- | --- | --- |
| 管理员配置 | 管理员分配后自动出现在列表，名称可以由管理员自定义 | 模型、协议及高级参数；不能修改名称、服务商、URL、Key | 直连服务的个人 Key 额度，不扣本站钱包 |
| 自定义直连 | 自己新建并填写服务配置 | 站点权限允许的名称、服务商、连接信息、模型和高级选项 | 自己的供应商额度，不扣本站钱包 |
| 本站 | 新建配置时选择“走本站” | 名称、模型、协议及高级参数；不显示连接信息 | 本站钱包 |

同一个人可以拥有多份管理员配置。初次进入可能自动选中管理员指定的默认配置，之后以你主动保存的选择为准。名称不一定叫“管理员配置”，也可能是管理员填写的其他名称。

管理员配置和本站配置不显示服务商、URL、Key，不代表配置不完整；这些字段不需要你填写。管理员配置实际直连时仍由浏览器发起请求，所以只应在可信设备登录。

### 使用管理员分配的配置

1. 在“设置 → API 配置”的“图片生成”列表选中管理员分配的生图配置。
2. 在“AI 策划”列表选中管理员分配的策划配置。
3. 确认没有“尚未分配／已撤销”等提示。
4. 模型和高级设置通常先保留管理员默认值；有明确需求时再修改。
5. 关闭设置，回到工作台使用。

只要该个人 Key 在中转站可用，本站钱包为 0 也可以直连。管理员刚保存配置后，刷新工作台或重新打开设置查看；如果仍没有，请让管理员确认分配给了正确的用户和用途。

### 新建自己的直连配置

1. 在对应用途的配置卡片右上角点击“管理 → 新建配置”。
2. 选择“自定义直连”。
3. 填写便于辨认的名称，选择服务商，填写其要求的 API 基础地址和 Key。
4. 选择或输入模型，确认接口类型与服务支持的协议一致。
5. 在对应配置列表选中这份配置。

生图和策划可以使用不同供应商。策划需要返回文本的 Chat Completions／Responses 服务；普通 Images 接口不能单独完成策划。

如果“新建配置”或某些字段被禁用，是管理员限制了相应操作。请联系管理员，不要把管理员分配配置中隐藏的连接信息当作需要补填的字段。

### 新建“走本站”配置

1. 在对应用途卡片中点击“管理 → 新建配置 → 走本站”。
2. 为配置命名，选择或输入本站支持的模型。
3. 按需调整高级设置，并确认当前选中的就是这份本站配置。
4. 到“账户与余额”确认本站余额，再提交请求。

本站配置不需要填写服务商、URL、Key。它会经过本站服务器并扣本站钱包，因此体验也受本站带宽和代理并发限制。本站没有配置好相应渠道或模型时，请联系管理员，不要改填其他 URL。

## 04 模型和高级设置怎么选

模型列表是推荐项，不是唯一支持的列表。知道准确模型 ID 时可以手动填写，但“能输入”不等于服务一定支持；最终由中转站或本站 New API 的渠道及用户权限决定。模型 ID 不应填写成请求 URL。

| 选项 | 使用建议 |
| --- | --- |
| API 接口 | 与所用服务的 Images、Responses 或 Chat Completions 协议对应；不确定时保留默认值 |
| 流式传输 | 支持的服务可逐步返回文本或图片；不是所有服务都支持 |
| 生图中间步骤图片数 | 仅在对应流式图片接口支持时有效；实际返回的中间图可能额外计费 |
| 返回 Base64 图片数据 | 服务支持时可避免结果图片 URL 的跨域下载问题，但会增加传输体积 |
| Codex CLI 兼容模式 | 仅按管理员／服务商建议启用，不是通用加速开关 |
| 请求超时 | 控制浏览器等待时间；超时不代表上游任务取消或没有收费 |
| 连续母图能力和最大片数 | 影响 A+ 连续母图请求；需要服务确实支持对应尺寸与能力 |

对管理员配置修改模型和高级选项，只影响自己当前账号在这个浏览器中的使用，不会改掉管理员模板，也不会让你取得连接编辑权限。更换浏览器或清空个人配置后，这些本地选项需要重新设置。

界面没有单独的总保存按钮时，按字段失焦、选择或开关操作保存；关闭设置后重新打开，可检查当前配置和参数是否保留。

## 05 从文案到图片的一次完整使用

1. **生成文案（可选）**：进入“Listing 文案”，填写商品事实、成本和重量，按需上传参考图，生成并检查中英文文案。使用的是 AI 策划配置。
2. **做图片策划**：回到首页，选择 Listing 图或 A+ 图，填写商品信息、图片数量／模块规格和参考图，然后进行 AI 策划。
3. **准备生图**：将需要的方案填入生图区，检查提示词、尺寸、参考图、风格图及输出格式。
4. **提交生成**：确认当前生图配置，逐张或按现有批量功能生成。不要把“AI 策划成功”当作图片已经生成。
5. **编辑与整理**：在“图片编辑”中进行 AI 编辑，或使用本地切图、等比放大和 A+ 转换准备。
6. **保存结果**：下载满意的图片，使用历史记录的收藏、搜索和批量下载整理成果。

文案、策划、知识库 AI 总结使用策划配置；AI 生图和编辑使用生图配置。浏览器本地切图、等比放大及历史整理本身不调用 AI，不扣模型费用；随后再次点击 AI 生成则是新的请求。

更具体的步骤见文档导航中的“Listing 图”“Listing 文案”“高级 A+”和“图片编辑”。

## 06 钱包、额度与充值

本站钱包与直连 Key 额度是两笔不同的额度：

- 管理员配置／自定义直连：个人 Key 的限额及供应商账户状态由中转站控制，本站不显示这部分余额。
- 本站配置：扣本站钱包；在“设置 → 账户与余额”点击“刷新余额与账单”查看近期消费。
- 人工充值时明确告诉管理员要充值哪一种。给本站钱包加款不会让一个额度已耗尽的直连 Key 恢复可用。

普通用户不用去 New API 管理端充值。目前尚无支付宝、微信自动到账入口，需要联系管理员。页面显示“免广告”相关规则也不表示广告服务已经上线。

一次工作流可能先调用策划，再调用多次生成；这些不是同一次请求。两种用途若选择了不同来源的配置，对应费用也会分别由各自的账户承担。

## 07 数据、退出与换设备

任务历史、生成图片、个人知识库、笔记和个人配置主要保存在当前浏览器中，平台模式按账号隔离；同一账号换到另一浏览器不会自动同步这些本地数据。

- 退出入口在“设置 → 账户与余额 → 退出登录”。在共享设备上使用后请退出。
- 清空配置、清空浏览器缓存或更换设备，不会注销服务器上的账号或清空本站钱包，但可能删除本地历史和自定义配置。
- 管理员后台分配的连接重新登录后仍可加载；自己的模型／高级选项需要从个人备份恢复。
- 清理前，在“设置 → 数据管理”导出需要的配置和历史；满意的图片也建议单独下载。
- 管理员配置导出仅包含引用和个人选项，不包含受保护的连接信息。自己的自定义配置备份可能含自己的 Key，不要直接公开分享。
- 旧纯前端数据不会自动归到第一个平台账号；先在原环境导出，再登录正确的目标账号手动导入。

## 08 常见问题

| 问题 | 怎么处理 |
| --- | --- |
| 没有注册／忘记密码入口 | 当前由管理员开通账户、重置密码，请联系管理员 |
| 配置名称灰色，找不到 URL 或 Key | 管理员配置和本站配置本来就隐藏连接字段；只需选择模型和高级选项 |
| 管理员配置尚未分配或被撤销 | 联系管理员，或按权限创建其他配置；系统不会自动切到收费代理 |
| 新建、修改地址或服务商按钮不可用 | 检查是否受到站点权限限制；不要重复充值来尝试“解锁” |
| 本站钱包有钱，直连却提示额度不足 | 两种额度独立，需处理直连 Key 的上游额度 |
| 模型不存在／无权限 | 核对准确模型 ID 和接口类型；手填模型也受供应商／本站权限限制 |
| 直连跨域失败 | 由服务商允许本站 Origin；不会自动通过本站转发 |
| 本站代理返回 429 | 当前请求过多，等待在途任务结束后再提交 |
| 本站代理返回 413 | 请求超过限制，减少或压缩参考图；直连按供应商限制处理 |
| 图片生成成功但下载失败 | 有结果链接时先重试下载已有结果，不要盲目重新生成 |
| 页面还像旧版 | 刷新页面；仍旧时重新打开站点或强制刷新，不要为了刷新版本直接删除历史数据 |

超时、停止或关闭页面不保证上游取消任务或退费。需要反馈时提供发生时间、配置名称、模型和错误提示，不公开 Key、Cookie 或完整认证请求头。管理员可以查本站代理记录，不能凭本站日志确认没有经过本站的直连请求。
