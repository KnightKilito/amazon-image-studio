# 图片尺寸弹窗拖拽选择误关闭修复

## Goal

修复图片尺寸调节弹窗中从文本框开始框选数字、在弹窗外松开鼠标时误关闭弹窗的问题，使遮罩关闭只响应完整发生在遮罩上的点击，并与设置页弹窗行为一致。

## Phases

- [completed] 定位图片尺寸调节弹窗及设置页遮罩关闭实现，确认根因和复用模式。
- [completed] 修复遮罩关闭手势判定并补充回归测试。
- [completed] 运行聚焦测试、全量测试、构建与差异检查。

## Decisions

- 只修正遮罩手势判定，不改变关闭按钮、Escape 键和确认操作。
- 采用 pointer/mouse 按下起点记录：必须在遮罩本身按下且在遮罩本身松开/点击才允许关闭。
- 保留当前工作区所有既有改动，只修改本缺陷相关文件与计划记录。

## Errors Encountered

- 首次把构建与全量测试并行运行时，构建超过工具单次等待窗口，仅返回“仍在 transforming”的中间输出；确认没有残留构建进程后单独重跑，明确以退出码 0 完成。
