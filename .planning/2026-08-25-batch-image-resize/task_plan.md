# 图片编辑页批量调整尺寸

## Goal

在图片编辑页增加基于浏览器 Canvas 的批量尺寸调整工具，允许从当前素材和结果图中多选图片、统一设置尺寸/适配方式/输出格式与质量，在执行前显示逐张及合计的预估输出大小，并将结果保存到现有派生任务历史。

## Phases

- [completed] 审计图片编辑页素材来源、Canvas 编码能力、任务持久化和现有单图放大流程。
- [completed] 实现通用批量尺寸计算、编码与文件大小预估逻辑，并补纯逻辑测试。
- [completed] 实现批量调整弹窗、图片选择和预估展示，接入编辑页本地工具区。
- [completed] 将批量结果保存为现有任务历史，并补 store 回归测试。
- [completed] 运行聚焦测试、全量 Vitest、生产构建、diff 检查及页面验证。

## Decisions

- 图片处理完全在浏览器 Canvas 中完成，不新增 API 或依赖。
- 默认按目标边界等比适应，同时提供固定宽高模式；允许缩小或放大。
- 输出格式支持 PNG、JPEG 和 WebP；JPEG/WebP 可调质量。
- 文件大小在执行前明确标为“预估”，执行后任务中的图片仍保存真实编码结果。
- 批处理结果作为一条 `done` 派生任务写入现有历史，输入引用保留所有源图片 ID。
- 工作区当前干净；后续若出现外部修改，继续只触碰本任务范围。

## Errors Encountered

- 新增弹窗的 SSR 测试最初断言了图片异步载入后才出现的估算说明；服务端静态渲染不会运行 `useEffect`，已改为断言首屏固定存在的“编码文件大小预估”说明，功能代码无需变更。
- 本地 Vite 首次启动尚未完成时浏览器提前访问，得到连接拒绝；确认服务监听后使用新标签成功载入编辑页。
- 页面上已有另一个名为“清空”的按钮，首次全局严格定位命中两个元素；根据可见诊断将交互限定到批量弹窗中的最后一个匹配项，验证通过。
- 本地开发环境未启动可选的 `/admin-api/settings` 代理服务，因此 Vite 日志有既有的 `ECONNREFUSED`；不影响纯前端编辑页和批量 Canvas 工具验证。
