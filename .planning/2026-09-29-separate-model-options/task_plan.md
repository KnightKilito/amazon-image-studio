# 区分图片与策划模型下拉列表

## Goal

管理员分别维护图片模型与策划模型的可选列表；用户设置页对应的模型字段既能自由输入，也能从各自列表选择。兼容已有管理员配置与现有用户配置。

## Phases

- [completed] 审计管理员模型列表的前后端结构和设置页两类模型输入。
- [completed] 实现两组管理员列表、兼容旧数据及服务端规范化。
- [completed] 实现图片/策划模型各自的可输入下拉选择。
- [completed] 补必要测试并运行全量测试、构建与 diff 检查。

## Decisions

- 已存的用户模型字符串继续原样有效，自定义输入不受下拉列表限制。
- 旧 `modelIds` 迁移时默认作为图片模型列表保留，避免丢失管理员已有选项。

## Errors Encountered

- 无。
