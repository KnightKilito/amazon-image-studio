# 图片结果页 A+ 母图切割类型选择

## Goal

将图片详情/结果页的切割入口统一为“切割 A+ 母图”，在切割弹窗中允许用户选择高级 A+ 或手机 A+ 比例与切片数量，并严格按用户选择的类型辅助校验母图比例和尺寸，避免依赖任务分类误判。

## Phases

- [completed] 审计详情页切割入口、格式推断、弹窗参数和比例校验逻辑。
- [completed] 调整弹窗为显式 A+ 类型 + 切片数量选择，并按选择实时校验。
- [completed] 修改详情页按钮文案与提交链路，保留编辑页现有显式类型行为。
- [completed] 补充逻辑/组件回归测试，运行全量测试、生产构建和 diff 检查。

## Decisions

- 用户在弹窗中的选择优先于任务分类推断；系统推断只用于弹窗默认值。
- 按钮统一文案“切割 A+ 母图”，不在按钮阶段声称已识别具体类型。
- 不修改 Canvas 切片算法和任务历史结构，只修正输入类型与校验来源。
- 工作区当前干净。

## Errors Encountered

- 首次切换活动计划时误写上一计划目录名为 `2026-09-17-batch-mobile-aplus-plan`；读取活动指针后确认实际为 `2026-09-17-batch-mobile-aplus-design`，未产生文件改动。
- 首次搜索测试文件时向 Windows `rg` 传入 `src/**/*.test.ts(x)` 通配路径，触发路径格式错误；后续改为搜索 `src` 目录并使用 `-g` 文件过滤。
