# 通用下拉样式与悬浮文字笔记

## Goal

把 Listing 文案页“商品预设”统一为项目现有紧凑下拉样式；在页面左侧增加可展开的悬浮笔记工具，允许用户把常用提示词以标题+正文的形式保存在浏览器本地，并完成搜索、新增、查看、编辑、删除和一键复制。

## Phases

- [completed] 审计 Select 组件样式、全局 App 挂载点、现有本地持久化与复制/确认交互。
- [completed] 设计笔记数据模型、localStorage 仓储函数、导入导出兼容和纯逻辑测试。
- [completed] 实现左侧悬浮球、笔记列表、搜索与 CRUD/复制交互。
- [completed] 统一 Listing 文案页商品预设下拉框样式。
- [completed] 将文字笔记接入现有导出包与导入恢复/合并流程。
- [completed] 运行聚焦测试、全量测试、生产构建与桌面/窄屏页面验证。

## Decisions

- 笔记日常保存在浏览器 localStorage，不加入服务端或 IndexedDB schema；同时作为可选字段进入现有导入导出数据。
- 每条笔记包含 `id/title/content/createdAt/updatedAt`；标题和正文均必填，按最近更新时间排序。
- 悬浮球固定左侧中部；展开面板在桌面向右展开，窄屏使用视口内浮层并保留安全边距。
- 删除使用现有确认弹窗或组件内二次确认；复制复用项目 clipboard helper 与全局 toast。
- 悬浮笔记是全局工具，挂载在 App 根级，三个主页面均可使用。
- 导入笔记按 ID 合并；同 ID 以 `updatedAt` 较新的版本为准，兼容不含笔记字段的旧导出包。
- 保留当前干净工作区；只修改本任务相关文件与规划记录。

## Errors Encountered

- 页面验证标签在用户继续后的新回合已由浏览器自动回收，主动关闭时返回“不属于当前会话”；没有遗留可见标签，也未重试该无效句柄。
- 本地 Vite 日志仍有可选 `/admin-api/settings` 服务未启动导致的既有 `ECONNREFUSED`，不影响本任务纯前端功能。
