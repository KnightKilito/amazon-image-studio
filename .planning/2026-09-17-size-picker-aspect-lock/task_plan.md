# 设置图像尺寸比例锁

## Goal

在“设置图像尺寸”的自定义宽高模式中增加比例锁按钮；锁定时修改任一边自动按锁定比例计算另一边，解锁后宽高可独立输入。

## Phases

- [completed] 审计 SizePickerModal 自定义宽高状态和批量尺寸窗口现有比例锁实现。
- [completed] 实现比例锁状态、同步换算和一致的锁按钮样式。
- [completed] 补充组件/换算回归测试。
- [completed] 运行聚焦测试、全量测试、生产构建与差异检查。

## Decisions

- 默认锁定打开窗口时的当前宽高比，与批量调整图片尺寸窗口保持一致。
- 锁定过程中输入为空或无效时，不覆盖另一边；重新输入有效正整数后恢复同步。
- 点击解锁后只改变锁状态，不修改当前宽高；再次锁定时以当时输入的有效宽高建立新比例。
- 保留当前工作区此前需求的未提交改动，只增量修改本需求相关文件。

## Errors Encountered

- `computer-use` 浏览器清单因控制端连接失败而不可用；改用组件静态渲染测试、共享换算函数测试和生产构建完成验收，不操作用户线上页面。
