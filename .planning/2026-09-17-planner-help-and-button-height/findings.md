# Findings

- 当前工作区包含此前已完成需求的未提交改动；本次仅修改 AmazonPlanner 的相关布局。
- 提示语“策划或生图失败可以先点击右边按钮看看”已存在于操作区下方蓝色提示条，但当前没有右侧内联按钮。
- 连通性说明入口当前是辅助网格中的完整“说明”按钮（36px 高），触发 `setShowConnectivityHelp(true)`；可以原样移动触发逻辑，只改成提示条右侧 24px 圆形问号。
- AI 策划和停止按钮使用 `h-10`（40px）；查看返回、清空策划案、清空输入、说明、设置使用 `h-9`（36px），这就是用户观察到的高度差。
- 辅助区还保留了一段被注释掉的 OpenAI 状态页链接 JSX；移动说明按钮时可一并移除死注释，实际状态页链接仍在说明弹窗内。
- 当前没有 AmazonPlanner 布局组件测试；本次为 CSS/节点位置调整，使用 TypeScript 构建、全量测试和源码结构复核验证。
- 辅助网格中的“说明”按钮及已注释的旧状态页链接已移除；提示条改为 flex 布局，文案占满剩余空间，右侧仅保留 24px 圆形问号并继续打开原说明弹窗。
- 查看返回、清空策划案、清空输入和设置均从 `h-9` 统一为 `h-10`，与 AI 策划和停止按钮同为 40px。
- 辅助区响应式列数调整为 2 / 3 / 4 列：大屏最多四个操作同排，中等宽度保持三列，窄屏两列，避免重新产生拥挤。
- 最终验证通过：46 个测试文件、437 项测试全部通过；生产构建和 `git diff --check` 通过，仅有项目既有的大 chunk 与 Windows LF/CRLF 提示。
