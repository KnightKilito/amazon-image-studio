# 首页快捷转手机 A+ 与 Listing 参考图按钮优化

## Goal

在首页图片结果卡片的收藏按钮右侧增加风格一致的“转手机 A+”快捷操作，复用现有转换能力；优化 Listing 文案页产品参考图三个操作按钮的排布和尺寸，使其不拥挤且视觉长度统一。

## Phases

- [completed] 审计结果卡片收藏按钮、现有手机 A+ 转换入口与 Listing 参考图操作区。
- [completed] 实现首页结果卡片快捷转手机 A+，补充必要的逻辑测试。
- [completed] 重构 Listing 产品参考图三个按钮的响应式统一布局。
- [completed] 运行聚焦测试、全量测试、生产构建与页面视觉验证。

## Decisions

- 优先复用项目已有手机 A+ 转换处理器、状态与图标，避免产生两套行为。
- 新按钮紧邻收藏按钮右侧，沿用结果卡片同组按钮尺寸、背景、悬浮和禁用反馈。
- Listing 三按钮采用等宽或统一最小宽度布局；桌面保持紧凑整齐，窄屏允许自然换行但不互相挤压。
- 保留当前工作区已有改动，只修改本需求相关文件与本计划记录。

## Errors Encountered

- 在 PowerShell 中把 `src/components/*.test.tsx` 作为 `rg` 位置参数会触发 Windows 路径通配符错误；后续改用 `rg --files src | rg '\.test\.tsx$'`，不重复该命令形式。
- 搜索转换测试时再次使用了同类位置参数通配符，触发相同 Windows 路径错误；已改为 `rg --glob '*.test.ts' --glob '*.test.tsx' ... src` 的仓库原生过滤方式。
- 真实页面验收时，内置浏览器拦截 `localhost`，`127.0.0.1` 无法从其隔离环境访问，且本机 Chrome 控制端不可用；改为完成完整测试、生产构建和源码 DOM/CSS 层级复核，并保留此限制说明。
