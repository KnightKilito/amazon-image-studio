## 已锁定决策
- 首版仅美国站，内部值为 `us`；旧数据缺省补为美国站。
- Item Name 与 Item Highlight 独立输出，英文分别限制为 75 和 125 字符。
- 默认鞋靴预设，同时提供通用商品预设。
- 燕文按总克重换算公斤后计算 `kg * 100 + 16`。
- 用户可编辑完整业务提示词，系统 JSON 契约和安全规则不可删除。
- 不重命名 npm 包、仓库目录、IndexedDB 数据库名或既有存储键。
- 保留工作区现有未提交改动，不回退或覆盖 Brand Story 相关实现。

## 错误记录
| 错误 | 处理 |
| --- | --- |
| PowerShell 环境没有 `sed` | 后续统一使用 `Get-Content`、`Select-Object` 或 `rg`。 |
| 首轮构建报 Select 调用参数和 `replaceAll` 编译目标不兼容 | 允许键盘调用无事件开关；改用全局正则替换。 |
| 浮点数使 70%+30% 的分母成为极小正数 | 用 `Number.EPSILON` 判断不可计算分母。 |
| 全量测试中的旧历史导入断言未包含新增站点默认值 | 更新断言验证旧记录导入后补为 `us`。 |
| 新增导出测试使用 1970 时间戳，ZIP 格式不接受 1980 年以前时间 | 测试数据改用 2023 年有效时间戳。 |
| 新增 API 测试 mock 未声明 fetch 参数，TypeScript 无法读取请求 body | 为 mock 补充完整 fetch 函数签名。 |
