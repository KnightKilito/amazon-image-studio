## 01 进入页面与配置

在顶部导航点击 **Listing 文案**。本页使用的是 **AI 策划配置**，与首页的生图配置分开：

1. 打开右上角 **设置 → 策划配置**，确认 API 地址、API Key、模型和接口类型可用。
2. 选择目标站点。当前页面按美国站规则生成英文主标题、辅助标题、五点、长描述和搜索词。
3. 如果页面提示“AI 策划配置待完善”，先点击 **去完善 AI 配置**，文案生成按钮会在配置通过校验后启用。

> 文案页不会直接调用生图配置。生成文案后，可将英文标题和五点复制到首页的 Listing 图或 A+ 图策划中继续使用。

## 02 填写产品资料

左侧 **产品资料与成本** 只填写已经确认的事实。资料越完整，文案越容易做到准确且不编造：

| 字段 | 填写建议 |
| --- | --- |
| **商品预设** | 鞋靴商品选择“鞋靴预设”，会额外显示鞋跟/鞋头、鞋底/防滑、穿戴方式、舒适性；其他商品选择“通用商品”。 |
| **产品介绍** | 说明商品是什么、解决什么需求、最重要的真实特点。建议优先填写。 |
| **品牌 / 型号、核心品类** | 使用真实品牌名、型号和 Amazon 类目，不要把营销口号当品牌事实。 |
| **材质、颜色与尺码、目标人群、使用场景** | 写清可验证的规格、适用人群和使用环境。 |
| **功能与卖点** | 一行一个事实或卖点，避免输入无法证明的“第一”“永久”等绝对表述。 |
| **必须包含的词 / 禁止使用的词** | 控制关键词、品牌写法和禁用词；最终仍需人工检查商标与合规风险。 |

### 产品参考图

- 点击 **上传参考图**，或将图片拖入参考图区域，最多 8 张。
- 建议上传产品正面、侧面、细节、包装和结构图；鞋类可补充鞋底、材质纹理和上脚角度。
- 参考图只用于确认产品外观事实，不会直接决定文案风格，也不会被当作视觉风格参考图。
- 生成前可删除不清晰或与当前 SKU 无关的图片。

## 03 填写成本与物流

右侧的利润卡片会根据输入实时测算，支持 FBM 与 FBA 两种履约方式。常用字段包括采购成本、国内运费、净重、包装增重、汇率、Amazon 佣金率、目标净利率和燕文费用；竞品价格区间、FBA 头程与配送费为选填。

- 不完整的成本不会阻止文案生成，但对应的利润卡片会显示“待补全成本数据”。
- **计费重量**按商品净重 + 包装增重计算，燕文费按公斤价和挂号费计算。
- 建议填写 **利润测算售价** 后再比较 FBM/FBA；未填写时使用系统计算出的建议售价。
- 竞品最低/最高价只用于提示价格是否偏离区间，不会覆盖你的成本模型。
- 佣金率与目标净利率之和必须小于 100%，汇率必须大于 0。

## 04 调整策划提示词

右侧 **Listing 策划提示词** 包含三个可编辑区域：

- **标题提示词**：控制 Item Name 与标题结构。
- **五点描述提示词**：要求严格五条，用具体的小标题和事实利益表达购买理由。
- **长描述提示词**：控制标题、卖点叙事、适用场景、规格说明和收尾结构。

每个区域都可以单独点击 **恢复**，也可以点击 **全部恢复默认**。系统固定契约不会被覆盖：JSON 输出结构、禁止编造规则，以及标题额外禁用逗号和独立单词 `and` 的约束始终保留。

点击 **查看内置知识库** 可以查看当前使用的标题 Prompt、SKU 文案笔记和 Amazon 规则原文，并复制当前知识库内容作为团队规范或复核材料。

## 05 生成与检查结果

点击 **生成 Listing 文案** 后，页面会显示生成状态；配置开启流式返回时可以点击 **查看流式数据**，也可以在生成过程中点击 **停止**。成功结果会自动保存为一条不可变历史版本。

结果区按以下顺序检查：

1. **AI 标题策划分析**：先看商品身份、关键词分层、图片识别节点和标题取舍，再决定是否修改。
2. **主标题 Item Name**：英文按 75 个可见字符提示长度，中文为对照文本；超限时会标红。
3. **辅助标题 Item Highlight**：英文按 125 个可见字符提示长度，保持与主标题独立，不会自动拼接。
4. **五点描述**：固定五条，可逐条编辑，也可以整组复制英文或中文。
5. **长描述**：同时提供纯文本编辑、安全 HTML 和中英文富文本预览；预览只转换有限 Markdown，不执行任意 HTML。
6. **核心关键词与 Backend Search Terms**：可直接编辑和复制，提交前检查重复词、品牌词和无效符号。
7. **缺失信息 / 合规提醒**：这是人工复核清单，不是自动批准结果。缺失事实不要直接补写到买家可见文案中。

## 06 优化当前文案与管理版本

生成结果后点击 **优化当前文案**，输入明确的局部修改要求，例如“保留标题，只强化五点中的防滑证据”。AI 会同时参考当前结果、原始产品资料和产品参考图，只修改你提出的部分，并把新结果保存为新的历史版本。

点击顶部 **历史版本** 可以：

- 查看每个版本的标题和生成时间；
- 点击 **恢复此版本** 把文案、输入资料、成本、提示词和参考图一起恢复；
- 删除不再需要的版本。

当前草稿和历史版本保存在浏览器本地。清空站点数据或更换浏览器前，请先复制文案或导出需要的结果。

## 07 与图片策划衔接

文案确认后，可按下面顺序继续做图：

1. 在 Item Name、五点描述或长描述区域复制英文内容。
2. 顶部切回首页，选择 **Listing 图** 或 **A+ 图**。
3. 把已确认的英文 Listing 文案和必要的品牌说明粘贴到策划输入框，再运行 AI 策划。
4. 在图片策划卡片中检查产品事实、尺寸、参考图和 Prompt Preview，不要把文案页的利润数字直接放入 A+ 图片。

## 08 常见问题

### 文案生成按钮不可用

检查设置中的策划 API 是否有 API 地址、Key、模型和文本接口权限。只有 Images API 的配置不能生成文案。

### 结果出现缺失事实或合规提醒

先补充产品资料和参考图，再使用 **优化当前文案**；不要让 AI 猜测没有提供的材质、认证、功能或品牌历史。

### FBA 没有利润结果

补充 FBA 头程/件和 FBA 配送费。FBM 则需要采购成本、国内运费、重量、汇率和燕文费用等共同成本数据。
