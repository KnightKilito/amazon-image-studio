# Findings

- 快捷笔记由全局 `FloatingNotes` 渲染，启动按钮固定在 `left: 0.5rem/0.75rem; top: 50%`，面板固定在左侧并同样垂直居中；没有位置状态或拖拽逻辑。
- 图片查看器 `Lightbox` 的上一张按钮位于左侧 `12/20px`、垂直 50%，Lightbox 根层级为 `z-[60]`；快捷笔记为 `z-[65]`，因此启动按钮会精确覆盖上一张按钮。
- 笔记内容本身存储在独立 localStorage；位置可使用新的轻量 localStorage key，不应混入笔记备份数据。
- 推荐默认把启动按钮中心下移到视口约 66%，保留顶部 Header 安全区；用户拖动时允许全视口移动，释放后按中心点吸附最近左右侧边，并对垂直位置做视口约束。
- 笔记面板需跟随吸附侧：左侧时向右展开，右侧时向左展开；垂直方向围绕启动按钮居中，并依据实际面板高度二次 clamp 防止出屏。
- 项目已有 Pointer Events 和 pointer capture 使用范例，可直接实现鼠标/触屏统一拖拽，无需新增依赖。
- 最终实现使用圆形启动按钮作为拖拽手柄，避免让面板内搜索、编辑和滚动操作与拖动冲突；面板头部明确提示“拖动圆形按钮可移动”。
- 拖动阈值为 5px，真正拖动后会抑制随后 click，避免松手时误开/误关笔记；单纯点击行为保持不变。
- 位置独立持久化到 `amazon-image-studio.floating-notes-dock.v1`，不会进入笔记导入导出内容；损坏/越界值会回退或重新 clamp。
