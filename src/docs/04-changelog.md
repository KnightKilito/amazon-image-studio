## v0.4.5

发布日期：2026-10-06

- 新增模型下拉框选择。
- 新增生成状态：下载中的状态。
- 优化快捷笔记悬浮窗，调整默认位置避免遮挡，以及现在可以拖拽悬浮窗了。
- 图片编辑页新增批量转为A+。

## v0.4.4

发布日期：2026-09-17

- 新增展示图片下载url。
- 优化按钮排版，新增快捷转为手机A+按钮。
- 修复图片尺寸配置丢失。
- 新增锁定比例修改图片尺寸。


## v0.4.3

发布日期：2026-09-11

- 新增Listing图尺寸选择。
- 新增连通性超链接。
- 优化页面排版。
- 新增快捷笔记悬浮窗。


## v0.4.2

发布日期：2026-08-27

- 新增同比修改图片尺寸按钮。
- 修复编辑页图片历史的多选功能。
- 完善编辑页排版。
- 切换tab不丢失草稿。



## v0.4.1

发布日期：2026-08-25

- 图片编辑新增批量修改图片尺寸。
- 新增填充风格图按钮。
- 修复首页图片拖拽。
- 修复策划中断。
- 优化Listing文案编辑页。

## v0.4.0

发布日期：2026-08-14

- 新增 Listing 文案页。
- 手机 A+ 页复用高级 A+ 功能模块。
- 细化高级 A+ 品牌策划：支持独立品牌故事与高级 A+ 同步策划 From the brand，并可配置前景卡片数量。
- 补充 Listing 文案页、图片编辑页和高级 A+ 品牌故事使用文档。

## v0.3.0

发布日期：2026-08-10

- 新增图片编辑页，支持 AI 编辑、遮罩、A+ 母图切割和本地处理。
- 生图和策划的配置分开。

## v0.2.2

发布日期：2026-08-05

- 新增AI策划流式开关，可以进入窗口查看流式返回的策划详情，以应对部分中转站接口超时被断开的情况。

## v0.2.1

发布日期：2026-08-04

- 下载图片时可写入 AI 生成标记，便于后续识别和管理。
- 历史记录支持分页浏览，降低大量任务同时渲染时的浏览负担。
- 修复新建 API 配置时的异常处理。
- 更新站内版本日志与应用版本标识。

## 2026-07-27 至 2026-08-02

- 高级 A+ 支持独立模块与自由编排，可组合连续母图、轮播图和品牌故事。
- 连续母图可在详情页按规划切割，并在切割前校验实际尺寸与比例。
- 高级 A+ 与手机 A+ 支持浏览器本地等比放大和批量处理，原图不会被覆盖。

## 2026-07-20 至 2026-07-26

- 新建任务与“编辑输出”统一默认使用 `PNG` 和 `high` 质量。
- 优化图片详情、模块概述、生成操作区和视觉风格编辑界面。

## 2026-07-06 至 2026-07-19

- 图片详情新增转为高级 A+、转为手机 A+ 的快捷入口。
- 新增显式风格参考图槽位，支持上传、替换、预览和移除；MAIN 主图不会带入风格图。
- 修复风格图上传问题，并优化 AI 风格图生成，减少模板化输出。

## 2026-06-22 至 2026-06-28

- 新增管理员登录与统一配置，可管理游客 API 权限、服务商类型、模型列表和参考图上限。
- Node 管理 API 支持 YAML / 环境变量配置与 MySQL 持久化。
- 改善同源 API 代理、浏览器直连模式和策划接口的兼容降级。
