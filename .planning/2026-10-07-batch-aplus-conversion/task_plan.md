# 单张与批量 A+ 转换

## Goal
执行已确认方案：单张弹窗选择 1–7 片且保留素材；批量默认主图/普通素材，可上传，逐行编辑提示词、尺寸粗估、提交/停止/重试；统一类型，最多 9 条并发；关闭/切页继续，刷新手动续跑。

## Phases
- [completed] 共享转换规格与可等待/停止的显式任务提交。
- [completed] 单张弹窗和保留素材的转换模式。
- [completed] 批量草稿、并发队列及表格弹窗。
- [completed] 停止竞态、图片引用清理与刷新恢复回归验证。
- [completed] 全量测试、构建和 diff 检查。

## Decisions
- 每行一张源图、n=1，PNG/high/无压缩；片数表示母图内部片数。
- 固定约束根据表格数据自动生成，主要转换描述可自由编辑。
- 草稿存图片 ID，不保存重复图片数据或 API 凭据。
- 最大并发 9，包括生成/下载/重连；失败独立，停止后禁止晚到结果复活。

## Errors
- 新测试发现配置快照先规范化会忽略旧结构根级 API Key；改为与现有 submitTask 一致，先解析当前生图 profile，再创建规范化快照。
- 一次 UI 点选因代码热更新后索引失效报 shadow-root 错误；重新读取页面状态后恢复。读取不存在的 tsconfig.app.json 失败，生产构建实际已通过，不依赖该文件继续操作。
- 最后补强素材删除时清除单张转换状态的补丁，第一次因文件内 hunk 顺序不符合源码位置未应用；调整补丁顺序后完成，无源码损失。
