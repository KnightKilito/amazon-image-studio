## 01 选择历史记录

| 设备 | 选择方式 | 取消方式 |
| --- | --- | --- |
| **桌面端** | 在空白处拖拽框选；按住 `Ctrl` 或 `⌘` 点击卡片，可添加或移除单项。 | 再次框选已选中的卡片，或点击卡片外空白处。 |
| **手机端** | 在历史记录卡片上左右滑动，即可选中或取消选中该卡片。 | 再次左右滑动同一卡片。 |

## 02 批量操作

选中一条或多条记录后，页面底部会显示批量操作栏：

- 取消当前选择。
- 全选当前筛选条件下可见的记录。
- 批量收藏或取消收藏。
- 批量下载所选图片。
- 批量删除不再需要的记录。

## 03 Agent 基础操作

以下是保留 Agent 入口的部署的兼容说明。当前常规工作台主要通过 Listing、A+ 与图片编辑完成工作；界面没有 Agent 入口时，不需要额外寻找或开启它。

1. **配置接口**：Agent 需要使用 Responses API 配置。
2. **网络搜索能力**：仅在部署提供该选项、且模型服务支持时使用；普通文案和图片工作流不要求开启网络搜索。
3. **引用图片**：输入 `@` 可引用参考图或前面轮次生成的图片；Agent 也会结合对话上下文中的图片。
4. **切换消息分支**：编辑某轮消息后重新发送，或重新生成某轮消息，会产生可切换的对话分支。
5. **管理生成结果**：Agent 生成的图片会同步到画廊；删除对话默认不会删除画廊中的图片记录。

## 04 数据与使用注意事项

> **浏览器数据需要自行保护**  
> 图片任务和多数个人配置保存在当前浏览器中。清空站点数据、浏览器数据或更换浏览器，可能造成不可恢复的数据丢失，请及时下载满意的图片。

> **接口错误请保留完整信息**  
> 反馈时提供发生时间、配置名称、模型、HTTP 状态码和错误提示。不要公开发送 Key、Cookie 或认证请求头；管理员配置隐藏的连接字段不需要用户自行提取。

## 05 常见问题

### 启动后打不开页面

普通平台用户只需打开管理员提供的网址；打不开时先确认网络并联系管理员，不需要自行运行服务。以下命令仅适用于自行运行纯前端源码的用户：

```powershell
npm ci
npm run dev
```

Windows 用户也可重新双击 `start-amazon-image-studio.bat`。

### AI 策划失败

确认“AI 策划配置”使用文本接口，模型不是纯图片生成模型。DeepSeek 请使用 `Chat Completions (/chat/completions)`；官方接口不接收参考图，应用会自动改为仅发送商品文本。仅提供 `/v1/images` 的中转接口不能用于 AI 策划。

### 生图失败

先确认当前选择的是管理员配置、自定义直连还是本站配置。检查模型和接口类型；自定义直连还需核对 URL、Key，管理员配置或本站渠道问题请联系管理员。普通图片生成通常使用 Images API；OpenRouter 图片模型使用 Chat Completions，实际支持范围以服务为准。

### 参考图或历史记录丢失

图片任务和大部分个人配置保存在当前浏览器。清空站点数据、更换浏览器或使用无痕窗口可能导致数据不可恢复；重要结果请及时下载。
