# 快捷笔记全局拖拽吸附

## Goal

解决图片查看器前一张按钮被快捷笔记遮挡的问题：下移默认位置，并让快捷笔记可在全局拖拽、松手后吸附左右侧边，同时始终限制在可视区域内。

## Phases

- [completed] 审计快捷笔记组件、当前定位层级、持久化方式与图片查看器导航区域。
- [completed] 抽取/实现拖拽坐标约束、左右吸附与窗口缩放修正逻辑。
- [completed] 接入快捷笔记展开/收起形态、默认下移位置和位置持久化。
- [completed] 补逻辑/组件测试，运行全量测试、构建和 diff 检查；后台界面验证因工具连接失败由自动化验证替代。

## Decisions

- 默认位置下移，避免与图片查看器左侧导航按钮重叠。
- 拖拽后吸附最近的左/右侧边，不允许超出视口或遮住顶部 Header。
- 优先复用现有笔记持久化机制；若没有位置字段，只新增轻量本地位置状态，不改后端。
- 工作区当前干净。

## Errors Encountered

- 后台电脑交互首次获取应用/浏览器清单时底层连接失败（`nodeRepl.fetch request failed`），没有可绑定窗口；按失败协议不重复同一路径，界面验证改用组件静态渲染、逻辑测试和生产构建。
