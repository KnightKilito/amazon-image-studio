# Listing 图尺寸持久化修复

## Goal

修复 Listing 图尺寸在用户修改后，刷新页面、组件重载或恢复页面状态时偶发回到默认值的问题；用户重新选择尺寸前，应持续使用最后一次明确选择的 Listing 尺寸。

## Phases

- [completed] 审计 Listing 尺寸的状态、持久化、初始化、清空和历史恢复链路。
- [completed] 设计并实现稳定持久化，兼容旧数据且不误用 A+ 尺寸。
- [completed] 补充刷新、重载与恢复场景的回归测试。
- [completed] 运行聚焦测试、全量测试、生产构建与差异检查。

## Decisions

- 最后一次由用户确认的 Listing 尺寸作为独立偏好保存，不能只依赖当前组件内存或某条策划历史。
- 页面初始化应同步读取持久值，避免先渲染默认值再由异步恢复覆盖产生竞态。
- 清空策划案、清空输入、切换 Tab 和普通刷新都不应清除 Listing 尺寸；只有用户重新选择尺寸才更新。
- 保留当前工作区上一需求的未提交改动，不回退或覆盖无关文件。

## Errors Encountered

- 搜索 planner 辅助文件时把 `src/lib/amazonPlanner*` 作为 PowerShell 位置参数，触发 Windows 通配符路径错误；其余搜索结果已定位真实文件，后续使用 `--glob` 或明确文件名。
- `computer-use` 浏览器清单仍因控制端连接失败而不可用；改用持久化合并测试覆盖刷新和重载，不操作用户线上页面。
